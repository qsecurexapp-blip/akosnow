Security Whitepaper & Architecture

A transparent look at how QSecureX handles key derivation, threat modeling, and memory protection.

1. Key Derivation & Stretching

Master passwords are processed using Argon2id (t=3, m=64MB, p=4) to produce a 256-bit Key Encryption Key (KEK). This ensures resistance against GPU-accelerated dictionary attacks.

2. File & Stream Encryption

Every file is assigned a unique 96-bit Initialization Vector (IV). Content is encrypted via AES-256-GCM, producing a 128-bit authentication tag that detects tampering before decryption.

3. Threat Model & Memory Hygiene

Cryptographic keys reside strictly in zeroed-on-exit volatile RAM. Inactive sessions trigger secure memory overwrite routines to prevent RAM cold-boot extraction.

4. Local Storage Structure

Metadata headers, file pointers, and vault indexes are stored inside encrypted SQLite headers. No plain-text index of file names or folder paths exists on disk.
