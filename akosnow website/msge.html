Setting up MSGE Inbox

1

Install MSGE Client

Download the desktop dashboard or mobile inbox application for Android and macOS. Log in with your corporate credential profile.

2

Retrieve Workspace Credentials

Go to settings in the MSGE dashboard to copy your Workspace ID and API Key. This secures and routes your integration tunnel.

3

Map Webhooks or Plugins

Connect Shopify, WordPress WooCommerce, or Google Forms using our pre-built plugins or simple REST post requests.

4

Receive Alerts and Close Deals

Watch incoming events drop into specialized workspaces in real time. Take action immediately and close invoices.
