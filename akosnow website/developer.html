Akosnow MSGE

MSGE Developer Integration Guide

Connect your clients' business websites and lead capture forms directly to the Akosnow MSGE app. Receive real-time push messages, chimes, and UI updates the second a customer makes an inquiry.

🚀

Direct Firestore Sync

Our Node backend writes leads straight to the `akosnow_alerts` collection target user, alerting the workspace admin dynamically.

⚡ API Sandbox Console

Customize values and trigger a real test payload to your local Express server endpoint (Port 5001).

> Ready to execute test API trigger...

Integration Steps

Step 1

Obtain Connection Key

Alerts require the target account's API Key (Firebase Auth User UID) to deliver notifications. This key is fetched from inside the mobile app profile screen.

Get Key from Settings

Download the Akosnow MSGE app, navigate to Settings / Profile, and copy your unique API Key / User UID.

Step 2

API Endpoint Specs

Dispatches are routed via standard JSON `POST` requests to our REST gateway. The gateway runs locally on port `5001` in the workspace backend router.

POST http://localhost:5001/api/business/lead
Field Type Req Desc
formType String Yes Origin form identifier label.
name String Yes Client's contact name.
email String Yes Valid customer email.
phone String Yes Contact phone number.
product String No Product interest label.
💡

Dynamic Custom Fields Support

You can send any extra custom key-value pairs in your JSON request body (e.g., message, budget, location). Akosnow MSGE will automatically format and display them dynamically in your MSGE app notification.

Step 3

Copy Implementation Code

Implement the secure backend route proxy on Node.js/Express, or write native async fetch event dispatchers inside browser submit handlers.

const express = require('express');
const fetch = require('node-fetch');
const router = express.Router();

// 1. POST webhook route on client server
router.post('/api/business/lead', async (req, res) => {
  const { name, company, email, phone, product } = req.body;
  
  try {
    const response = await fetch("https://api.akosnow.com/v1/leads", {
      method: "POST",
      headers: {
        "Content-Type": "application/json"
      },
      body: JSON.stringify({
        workspaceId: "WS_84HK91",
        apiKey: "ak_live_xxxxxxxxx",
        event: "lead",
        data: {
          name: name,
          company: company,
          email: email,
          phone: phone,
          product: product,
          source: "Website Lead Form"
        }
      })
    });

    const result = await response.json();
    res.json(result);
  } catch (error) {
    res.status(500).json({ success: false, error: error.message });
  }
});// 2. Frontend event handler for capture form submission
const submitLeadForm = async (event) => {
  event.preventDefault();

  const payload = {
    workspaceId: "WS_84HK91",
    apiKey: "ak_live_xxxxxxxxx",
    event: "lead",
    data: {
      name: document.getElementById('fullName').value,
      company: document.getElementById('companyName').value || "N/A",
      email: document.getElementById('emailAddress').value,
      phone: document.getElementById('phoneNumber').value,
      product: document.getElementById('productInterest').value,
      source: "Website Lead Form"
    }
  };

  try {
    const response = await fetch("http://localhost:5001/api/business/lead", {
      method: "POST",
      headers: {
        "Content-Type": "application/json"
      },
      body: JSON.stringify(payload)
    });
    
    const result = await response.json();
    if (result.success) {
      alert("Lead alert successfully dispatched to MSGE app!");
    }
  } catch (error) {
    console.error("Integration failed:", error);
  }
};
